# Academic Rescue

**Веб-приложение для раннего выявления учебных трудностей и организации персональной поддержки студентов.**

Academic Rescue анализирует оценки, посещаемость и пропущенные дедлайны, чтобы помочь преподавателю заметить ухудшение успеваемости, подготовить план помощи и отслеживать дальнейший прогресс.

## Возможности

### Панель преподавателя

- Сводка по учебной группе.
- Список студентов с приоритетом по необходимости поддержки.
- Три статуса: **«В норме»**, **«Наблюдение»** и **«Требуется вмешательство»**.
- Карточка студента с оценками, посещаемостью, слабыми темами и ближайшими дедлайнами.
- Отображение учебной динамики и прогноза итоговой оценки.

### Анализ академического риска

- Расчёт индекса риска от 0 до 100.
- Определение уровня риска: низкий, средний, высокий или критический.
- Выявление устойчивого снижения оценок и ранних тревожных признаков.
- Определение курса, по которому студенту прежде всего нужна помощь.
- Расчёт необходимого среднего балла для достижения целевого результата.

### Персональная поддержка

- Подготовка учебного плана с учётом проблемных тем, посещаемости и сроков.
- Подбор материалов из локального каталога.
- Подтверждение плана преподавателем.
- Сохранение предупреждений и сообщений студенту в деморежиме.
- Регистрация повторной проверки.
- Логика оценки прогресса после оказанной поддержки.

### Интерфейс студента

- Отдельное демонстрационное представление для студента.
- Возможность подтвердить понимание плана, запросить помощь преподавателя или сообщить о выполнении задания.
- Сохранение ответов для дальнейшего рассмотрения преподавателем.

## Как это работает

1. Система получает учебные данные из локального демонстрационного набора.
2. Анализирует оценки, их динамику, посещаемость и пропущенные сроки.
3. Определяет статус студента и приоритет поддержки.
4. Преподаватель изучает причины риска и подтверждает необходимые действия.
5. Новые результаты могут использоваться для оценки эффективности помощи.

Первичная оценка выполняется по заданным правилам. В проекте также предусмотрены модули агента и инструменты для интеграции с OpenAI. В текущем веб-демо ИИ не подключён.

## Локальный запуск

Понадобятся Node.js и npm.

### 1. Скачать проект

```bash
git clone https://github.com/Roka-popka/academic-rescue.git
cd academic-rescue
```

### 2. Запустить сервер

```bash
npm install
npm run server
```

API будет доступен по адресу `http://localhost:3001`.

### 3. Запустить интерфейс

В отдельном терминале из папки проекта:

```bash
cd frontend
npm install
npm run dev
```

Откройте `http://localhost:5173`.

### 4. Запустить тесты

Из корневой папки проекта:

```bash
npm test
```

Для сборки интерфейса:

```bash
cd frontend
npm run build
```

## Статус проекта и ограничения

Проект находится на стадии демонстрационного прототипа.

- Используются локальные демонстрационные данные.
- Изменения хранятся в памяти сервера и сбрасываются после перезапуска.
- Переключение между преподавателем и студентом демонстрационное и не заменяет авторизацию.
- Уведомления сохраняются локально, без реальной отправки.
- Повторная проверка регистрируется как запись, без автоматического запуска по расписанию.
- Веб-демо показывает пятую неделю семестра.
- Индекс риска и прогноз оценки основаны на эвристиках и требуют проверки на реальных данных. Индекс риска не является вероятностью неуспеваемости.

Academic Rescue помогает преподавателю принимать решения о поддержке студентов; окончательное решение остаётся за человеком.
